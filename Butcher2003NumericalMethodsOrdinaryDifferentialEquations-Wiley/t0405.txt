For nonstiff problems, it seems to be advantageous to choose A = 0, whereas
for stiff problems, it is necessary that A > 0, if A-stability is to be achieved.
Furthermore, as we have already remarked, parallel evaluation of the stages
is only possible if A is a diagonal matrix; specifically this would be the zero
matrix in the nonstiff case. From these considerations, we introduce the ‘types’
of a DIMSIM method, and we retain this terminology for methods with a
similar structure.
