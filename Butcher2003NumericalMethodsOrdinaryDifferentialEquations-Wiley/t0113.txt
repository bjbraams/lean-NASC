243 Consistency, stability and convergence

Suppose we attempt the numerical solution of the simple differential equation
y'(x) = 0, with exact solution y(x) = 1, using the linear multistep method
characterized by the pair of polynomials [a, f]. If the exact answer has already
been found for k steps in a row, it seems to be a desirable property of the
method that the exact value is also found in one further step. This computed
value is equal to a; + a2 +--- + ax. For this expression to have the value
1 is equivalent to the assumption that a(1) = 0 or, what is equivalent, that
p(1) = 0. Because of its fundamental importance, this property will be given
the name ‘preconsistency’.
