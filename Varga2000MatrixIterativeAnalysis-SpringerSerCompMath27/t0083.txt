Lemma 3.7. Let B = L+U be a nonnegative nxn Jacobi matric. If p(B) >
0, then the functions m(c) and n(c) are both strictly increasing for o > 0. If
p(B) = 0, then m(c) = n(o) = 0 for all o > 0.

Proof. For convenience, we shall assume here that the nonnegative matrix B
is irreducible so that p(B) > 0. (For the reducible case, see Exer. 1 of this
section). Thus, neither L nor U is the null matrix. For o > 0, the nonnegative
matrix M(c) = oL +U has the same directed graph as does B, so that M(c)
is also irreducible, and we see from the Perron-Frobenius Theorem 2.7 that
increasing o increases the spectral radius of M(c). The same argument shows
that n(c) is also a strictly increasing function, which completes the proof for
the irreducible case. i
